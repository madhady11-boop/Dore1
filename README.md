# دوري صوب الشامية — المنصة الرسمية

منصة كاملة لإدارة وعرض دوري الدرجة الأولى للفِرَق الشعبية (الشامية): موقع عام بزجاجية (Glassmorphism) وتصميم ذهبي فخم،
بالإضافة إلى **لوحة تحكم مستقلة تماماً** لإدارة البطولة، و**لوحة خاصة لكل فريق** لإدارة التشكيلة والصور.

---

## ✨ المميزات

### الموقع العام
- صفحة رئيسية حية: المباراة القادمة، أحدث النتائج، الترتيب المختصر، الهدافون، آخر التبليغات، ومؤشرات البطولة.
- جدول المباريات مع تصفية حسب الحالة/الجولة وبحث بالاسم أو الملعب.
- جدول ترتيب محتسب آلياً من نتائج المباريات (النقاط ← فارق الأهداف ← الأهداف المسجلة) مع سجل آخر 5 مباريات.
- صفحات الفرق وبطاقات اللاعبين بصور وشعارات حقيقية.
- **مخطط التشكيلة (Formation Pitch)** مرتّب حسب الخطوط: حراسة / دفاع / وسط / هجوم، مع قائمة الاحتياط.
- التبليغات الرسمية ولوحة الانضباط والهدافين.

### لوحة التحكم (منفصلة تماماً عن الموقع العام)
- واجهة إدارية خاصة بشريط جانبي مجمّع حسب الصلاحيات، وشريط علوي، وتصميم زجاجي داكن.
- **الفرق والشعارات**: إضافة/تعديل/حذف + **رفع شعار الفريق** بالضغط أو السحب والإفلات (يُضغط تلقائياً).
- **اللاعبون والتشكيلات**: بطاقات اللاعبين + **رفع صورهم** + تحديد الخط التكتيكي وترتيبهم داخل كل خط (أسهم أعلى/أسفل)
  و«ترتيب تلقائي» حسب أرقام القمصان.
- **المباريات والنتائج**: جدولة، إدخال نتيجة بمُدخِل رقمي (Stepper)، تغيير الحالة، وإعادة احتساب الترتيب بضغطة واحدة.
- **جدول الترتيب**: عرض محسوب + تعديل يدوي للإحصائيات.
- **الحكام** بصورهم، **العقوبات والاعتراضات**، **المالية والغرامات** (مبنية على القرارات)، **المستخدمون والصلاحيات**،
  و**الإعدادات** (حالة الاتصال، قواعد التخزين الجاهزة، نسخة احتياطية JSON).

### لوحة الفريق
- إدارة كشف اللاعبين وصورهم وشعار الفريق، ترتيب التشكيلة، متابعة المباريات والعقوبات، وتقديم الاعتراضات رسمياً.

### الأدوار والصلاحيات
`مدير عام` · `مدير البطولة` · `لجنة الانضباط` · `مدير الإعلام` · `مدير الإحصاء` · `حساب فريق`
(كل دور يرى فقط الأدوات المصرّح بها — التحقق يتم في الواجهة وفي `firestore.rules`).

## 🔐 تهيئة Firebase (مهم لرفع الصور)

1. **تسجيل الدخول**: من صفحة `/login` عبر حساب Google. أول مستخدم بصلاحيات المدير العام (حسب `AuthContext`) يُنشأ له
   ملف في `users/{uid}` بدور `super_admin`.
2. **ربط الفرق بحساباتها**: من لوحة التحكم ← «المستخدمون والصلاحيات» اختر حساب الفريق وحدّد الفريق المقابل.
3. **تخزين الصور**: انسخ محتوى `storage.rules` والصقه في
   `Firebase Console ← Storage ← Rules ← Publish`. بدون ذلك سيعرض رافع الصور تنبيهاً ويقترح لصق رابط صورة كبديل.

### وضع العرض التجريبي
إذا كانت قاعدة البيانات فارغة تماماً (لا فرق/لاعبين/مباريات)، يعرض الموقع **بيانات نموذجية** مع شريط تنبيه ذهبي،
ليتمكن الجميع من رؤية التصميم والمخططات. تختفي البيانات النموذجية تلقائياً بمجرد إضافة أول فريق.

## 🗂️ بنية المشروع (مختصر)

```
src/
├─ components/
│  ├─ ui/            # نظام الواجهة: Button, GlassCard, Badge, Modal, Toast, Form, Tabs, StatTile…
│  ├─ football/      # Avatars, MatchCard, StandingsTable, FormPitch (مخطط الملعب), FormPills
│  └─ media/         # ImageUploader (ضغط + رفع إلى Firebase Storage)
├─ hooks/            # useTournamentData — مخزن مشترك لكل بيانات البطولة مع تحديث فوري
├─ layouts/          # MainLayout (عام) · AdminLayout (لوحة الإدارة) · TeamLayout (لوحة الفريق)
├─ lib/              # utils, constants, stats (احتساب الترتيب), images (الضغط والرفع), demoData
└─ pages/
   ├─ public/        # Home, Matches, Standings, Teams, TeamProfile, PlayerProfile, Announcements
   ├─ admin/         # 11 صفحة إدارية
   └─ team/          # 6 صفحات لحسابات الفرق
```
